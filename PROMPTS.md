# Prompts to paste into Muse

> **NOT READY.** The site is not deployed, so these links do not work yet. After deploying, put the site address in `config.json` and run `python3 make_prompts.py` again.

Rules for every run:

1. Start a **new chat** each time, so an earlier answer cannot carry over.
2. Paste the prompt exactly as written. Do not add or change a word.
3. Do not open the links yourself before or during the run. Your visit would show up in the server log next to Muse's.
4. Copy Muse's full answer, then run `python3 record.py <run id>` and paste it.
5. Go in the order below. The run id tells you nothing about which page lies, and that is on purpose.
